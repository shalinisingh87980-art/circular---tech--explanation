# Circular Tech Explanation

## 📌 About the Project
This project explains the concept of Circular Technology in a simple and easy-to-understand way.

## 🎯 Objective
The main objective is to promote sustainable use of technology by reducing electronic waste, reusing resources, and recycling electronic products.

## 🌱 Key Features
- Reduce e-waste
- Reuse electronic components
- Recycle old devices
- Promote sustainable technology

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
